# レビューチェックリスト

デッキを書き終えたとき、既存デッキを見直すときに使う。「機械」は `scripts/lint_deck.py` が検出する項目、「目視」は PNG に書き出して確認する項目、「内容」は Markdown を読んで判断する項目。

## 全体の構成（内容）

- [ ] デッキ全体の結論が、最後のまとめスライドに 1〜3 項目で書かれている
- [ ] 1 スライド 1 メッセージになっている。見出しだけを順に読んで話の流れが通る
- [ ] 見出しが「概要」「結果」のような名詞だけでなく、そのスライドで言いたいことになっている（図のスライドは特に）
- [ ] 最後が「ご清聴ありがとうございました」だけのスライドになっていない（機械: `thanks-slide`）
- [ ] 縦横比（`size`）が会場のプロジェクタに合っている

## 1 枚の情報量

- [ ] 本文が多すぎない。目安は 8 行・200 字以内（機械: `too-many-lines` / `too-many-chars`）
- [ ] 箇条書きは 5 項目程度まで、各項目は 1 行に収まる
- [ ] 読み上げる原稿がスライドに書かれていない（発表者ノートに移す）
- [ ] 収まらない内容は、詰め込まずにスライドを分けている

## 配置と余白（目視）

- [ ] 視線が上→下、左→右に流れる。フロー図や手順が右から左・下から上になっていない
- [ ] 要素の端が揃っている
- [ ] 文章が左揃え（機械: `centered-text`）
- [ ] 四辺と、テキストと図の間に余白がある。画像が端まではみ出していない
- [ ] 関係するもの（写真と説明など）が近くにあり、関係しないものは離れている
- [ ] 大事なことがスライドの下端に置かれていない（低いスクリーンで後ろの席から見えない）

## ノイズ

- [ ] ロゴが表紙以外に出ていない。header / footer にロゴがない（機械: `logo-repeated`）
- [ ] 内容と関係ないイラスト・飾りの画像がない
- [ ] header / footer / ページ番号が本当に必要なものだけになっている

## フォント

- [ ] 本文が 37px（28pt）以上（機械: `small-font`）
- [ ] 画像の中の文字（グラフの軸ラベルなど）も、スライド上で読める大きさ（目視）
- [ ] ゴシック体（BIZ UDPGothic 等）で描画されている。PDF で代替フォントになっていない（目視）
- [ ] 縁取り・影・斜体などの文字装飾がない
- [ ] 数値と単位があるところは、単位が小さい（`<span class="unit">`）

## 色

- [ ] 有彩色が 3 色以内（機械: `too-many-colors`）。グラフ画像の色もテーマの色に揃っている（目視）
- [ ] アクセントカラーは 1 枚に 1〜2 箇所で、本当に大事なところだけ
- [ ] 塗りと枠線を同時に使っていない
- [ ] 文字と背景のコントラストが十分（薄い背景に濃い文字、濃い背景に白い文字）
- [ ] 赤と緑、ピンクと緑などの見分けにくい組み合わせだけで意味を区別していない
- [ ] 彩度の高すぎる色（原色）を広い面積で使っていない

## グラフと表（目視・内容）

- [ ] 伝えたいことに合った種類のグラフになっている（[charts-tables.md](charts-tables.md)）
- [ ] 棒グラフの軸が 0 から始まっている
- [ ] 3D・影・グラデーションがない。目盛線・枠線が最小限
- [ ] 円グラフは 12 時から大きい順、項目は 6 個以内。ドーナツ型でない
- [ ] 強調したい項目だけ色が違う
- [ ] 表に縦罫線がなく、数値が右寄せ

## 著作権

- [ ] 他人の図表・写真を使った箇所に出典がある
- [ ] Web 公開する場合、引用の要件を満たさない他人の著作物が含まれていない
