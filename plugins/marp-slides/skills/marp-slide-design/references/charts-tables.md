# グラフと表

グラフはデータを整理して見やすくするためのもの。正しく、ひと目で読めることを最優先にし、装飾は削る。原則の出典は [design-principles.md](design-principles.md) を参照。

## グラフの種類を選ぶ

| 伝えたいこと | グラフ | 守ること |
|-------------|--------|---------|
| 量の大小を比べる | 縦棒 | **縦軸は必ず 0 から**（省くと面積の比が数値の比と合わず、30 と 40 が倍に見える）。棒の間隔は棒の幅の半分程度、本数が少なくても 1:1 まで |
| 順位をつける / 項目名が長い・多い | 横棒 | 長い順に上から並べる。長さを比べにくいので、棒の横に数値を書く |
| 時系列の増減 | 折れ線 | 横軸は等間隔。縦軸は 0 から始めなくてよいが、範囲を狭めて変化を誇張しない。上下に余白を残す |
| 全体に占める割合 | 円 | 大きい順に、12 時の位置から時計回り。項目は 5〜6 個まで（残りは「その他」）。ドーナツ型は中心角が見えず比較しにくいので避ける |
| 項目の構成比を比べる | 帯（100% 積み上げ横棒） | 項目の並び順を全帯で揃える |
| 複数項目のバランス・傾向 | レーダーチャート | 比べる対象は 2〜3 個まで |
| 2 つの量の関係 | 散布図 | 軸ラベルに単位を書く |

## グラフから削るもの

- **3D**: 奥行きで値が読めなくなり、手前の要素が大きく見えて誤解を招く。必ず 2D にする
- **影・グラデーション・光彩・立体**: 情報を持たない装飾
- **目盛線**: 目に入ると読み取ろうとしてしまう。最小限にするか、値を直接ラベルにしてなくす
- **棒や扇形の枠線**: 塗りがあれば枠は不要
- **大きすぎるマーカー**: 折れ線の変化が見えにくくなる。小さくするか、なくす
- **凡例**: 系列が少なければ、線や棒の近くに直接ラベルを書いて凡例をなくす

## グラフの色

- 色は少なく。基本は 1 色（グレーかベース寄りの色）で、**説明したい項目だけアクセントカラー**にする
- 系列を色で分ける必要があるときも、テーマの 3 色＋グレーの濃淡で収める
- 赤と緑など見分けにくい組み合わせで系列を区別しない。直接ラベル・線種・マーカー形状も併用する
- 照明が明るい会場では薄い色が飛ぶので、濃いめにする

## Marp にグラフを入れる

Marp 自体にグラフ描画機能はない（Mermaid も標準では描画されない）。グラフは別途画像にして貼る。

- **SVG で書き出す**。拡大しても劣化せず、PDF でも鮮明
- 画像の文字（軸ラベル・数値）も、スライド上で 37px 相当以上になるようにする。matplotlib なら 1280px 幅に貼る想定で `font.size` を 20〜24pt 程度にし、実際に描画して確認する
- グラフにタイトルを入れず、スライドの見出しで「何が言えるか」を書く（例: 「2023 年に利用者が 1.5 倍に増えた」）
- 大きく見せたいときは `figure` クラスでスライドタイトルを省く

### matplotlib の設定例

```python
import matplotlib.pyplot as plt

BASE_GRAY = "#B8B8B8"
ACCENT = "#D9730D"
TEXT = "#222222"

plt.rcParams.update({
    "font.family": ["BIZ UDPGothic", "Hiragino Sans", "Noto Sans JP", "sans-serif"],
    "font.size": 22,
    "axes.spines.top": False,
    "axes.spines.right": False,
    "axes.grid": False,
    "axes.edgecolor": TEXT,
    "axes.labelcolor": TEXT,
    "xtick.color": TEXT,
    "ytick.color": TEXT,
})

labels = ["りんご", "みかん", "マンゴー", "ぶどう"]
values = [40, 60, 85, 30]
colors = [ACCENT if l == "マンゴー" else BASE_GRAY for l in labels]

fig, ax = plt.subplots(figsize=(12, 6))
bars = ax.bar(labels, values, color=colors, width=0.6)
ax.bar_label(bars, padding=6)
ax.set_ylim(0, max(values) * 1.15)
ax.set_yticks([])
ax.spines["left"].set_visible(False)
fig.tight_layout()
fig.savefig("images/fruits.svg", transparent=True)
```

## 表

- **横罫線は見出しの下と最下部だけ**。縦罫線・セルの枠は引かない（テーマで設定済み）
- 原色の背景色を使わない。行の塗り分けも基本は不要
- 文字列は左寄せ、**数値は右寄せ**にして桁を揃える。数値は半角
- 単位は見出しに書き、セルには数値だけを書く（例: 見出し「売上（万円）」）
- 行・列が多い表はそのまま載せない。伝えたい行だけに絞るか、グラフにする

Markdown の表では、列の区切り行で寄せを指定する。

```markdown
| 地域 | 利用者数（人） | 前年比 |
|------|-------------:|------:|
| 東京 | 12,400 | 1.5 |
| 大阪 | 8,100 | 1.2 |
```

強調したいセルは `**12,400**` のように太字にすると、テーマでアクセントカラーになる。
