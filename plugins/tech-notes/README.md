# tech-notes

作業中に得た技術的な知見を、匿名化して個人用ノートリポジトリ `~/tech-notes` に記録するためのプラグイン。

## 収録物

| 種類 | 名前 | 内容 |
|------|------|------|
| skill | `note`（`/note [話題のヒント]`） | 知見の選定、既存ノートとの重複確認、執筆、匿名化の確認までを行う |

## 前提

- `~/tech-notes` が clone 済みで、pre-commit フック（gitleaks・禁止語チェック）が設定済みであること
- `model-routing` プラグインを推奨する。無くても、メイン会話が探索と執筆を代わりに行うので動く

## ノートのルール

ノートの書き方、匿名化ルール、置き場所、ファイル名の規則は `~/tech-notes/CLAUDE.md` に持つ。skill にはルールを複製せず、実行時にそのファイルを読ませる。
